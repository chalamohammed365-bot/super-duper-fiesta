# NovaShop Ethiopia - Smart Watch Landing Page

## 🎯 Project Overview
A modern, dark futuristic landing page for NovaShop Ethiopia's premium smart watch product. Built with pure HTML, CSS, and JavaScript for optimal performance.

## ✨ Features

### Core Sections
- ✅ **Hero Section** - Eye-catching welcome with animated CTA buttons
- ✅ **Product Showcase** - 3 premium product highlight cards
- ✅ **Features Section** - 6 advanced smart watch features
- ✅ **Customer Testimonials** - 3 verified customer reviews with ratings
- ✅ **FAQ Section** - 6 expandable frequently asked questions
- ✅ **Trust Badges** - Security, delivery, returns & support badges
- ✅ **Contact Section** - Multiple contact channels
- ✅ **Responsive Footer** - Comprehensive footer with links & payment methods

### Design & UX
- 🌙 **Dark Futuristic Theme** - Cyan (#00d4ff) & Purple (#9d4edd) color scheme
- 📱 **Mobile Responsive** - Optimized for all devices (480px - 1920px+)
- ⚡ **Fast Animations** - Smooth scroll effects with AOS library
- 🎨 **Glassmorphism** - Modern frosted glass UI elements
- ✨ **Glow Effects** - Neon-style glowing elements

### Performance & Optimization
- 📊 **Facebook Pixel Integration** - Track conversions & user behavior
- 🔗 **WhatsApp Integration** - Direct order links with pre-filled messages
- 📈 **SEO Optimized** - Meta tags, semantic HTML, structured content
- ⚙️ **Performance Optimized** - Debounced scroll events, lazy loading
- ♿ **Accessibility** - Keyboard navigation, focus states, ARIA labels

## 🚀 Quick Start

### Installation
1. Clone the repository:
```bash
git clone https://github.com/chalamohammed365-bot/super-duper-fiesta.git
cd super-duper-fiesta
```

2. Open in browser:
```bash
# Simply open index.html in your browser
open index.html  # macOS
start index.html  # Windows
xdg-open index.html  # Linux
```

### Configuration

#### Update Facebook Pixel ID
Edit `index.html` (line ~330) and `styles.css`:
```javascript
fbq('init', 'YOUR_PIXEL_ID'); // Replace with your actual pixel ID
```

#### Update WhatsApp Number
The WhatsApp number is set to `0983156393`. To change it, search for:
```html
href="https://wa.me/0983156393?text=..."
```

#### Update Contact Information
Edit the Contact Section in `index.html` with your details:
- Phone number
- Email address
- Location
